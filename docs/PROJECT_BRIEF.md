# ValueScope 项目简介

ValueScope 是一个面向 A 股研究的多源数据与多 Agent 分析平台。它的核心目标是把“找股票数据、补行情、看新闻、跑分析、查历史结论”这些分散动作统一到一个可部署的 Web 系统里。

## 一句话定位

一个可演示、可部署、可扩展的 A 股投研工作台：用自动化数据采集构建股票资料包，再用多 Agent 生成结构化投资分析。

## 主要能力

1. 股票检索与资料包
   - 支持代码、名称、拼音和首字母检索。
   - 尽量抓取可获得的全部历史数据，而不是只取最近几年。
   - 将行情、财务、估值、资金、公告、新闻等数据归档到本地资料包。

2. 行情与分钟数据补采
   - 支持手动补采指定股票分钟行情。
   - 支持空闲预抓：一段时间没有用户请求时，自动抓取尚未建立完整资料包的股票。
   - 后台可查看统一运维状态、任务进度、数据覆盖、日志入口和异常。
   - 重 IO 任务会自动互斥，避免全市场日 K、分时冷数据上传和空闲分钟预抓同时挤占服务器。

3. 新闻数据与新闻库
   - `NewsCrawler` 是独立服务，负责抓取新闻并写入 MongoDB。
   - `NewsAnalysis` 只读消费 `news.raw_articles`，保持采集和分析边界清晰。
   - 后台“新闻数据”页只读展示新闻库、来源分布、采集运行和失败原因。

4. 多 Agent 分析
   - 支持价值投机、质量成长价值、低估红利价值、超跌反弹等分析框架。
   - 多个 Agent 分别负责估值、财务、资金、催化、风险和最终汇总。
   - 分析结果可持久化，后续可直接读取历史运行。

5. 权限与只读模式
   - 管理员账号支持 TOTP 二次验证。
   - 管理员、只读管理员、注册用户和只读展示账号分离。
   - 访问与安全页面统一管理用户、邀请码、归档账号和系统凭据。
   - `admin_view` 只读账号可用于安全演示和只读巡检，所有写操作都会被后端拦截。

## 技术栈

- Backend: Python, `http.server` 自定义 Web 服务, MongoDB, Docker Compose
- Frontend: 原生 HTML/CSS/JavaScript，无重型前端框架
- Data: 东方财富、AkShare 候选源、同花顺新闻、开盘啦、通达信链路、历史 Tushare 资料包兼容
- AI: DeepSeek / 多 Agent 分析链路
- Ops: 加密密钥库、任务审计、远程部署脚本、CI/部署工作流

## 工程亮点

- 不是“单次脚本”，而是长期运行的 Web + Scheduler + Crawler 系统。
- 新闻采集独立成 `NewsCrawler`，通过 `news.v1` 契约与分析端解耦。
- 1.4 将运维状态、数据抽检和审计日志集中到系统治理页，并新增股票存储状态与随机数据健康检查。
- 后台所有外部数据访问和模型调用都要求审批，并写入审计记录。
- 只读展示账号在后端强制拦截 POST，避免演示时误触发真实任务。
- 股票来源被统一映射为标准数据类型，便于后续替换或增加 provider。

## 推荐查看路径

1. 打开首页和“项目介绍”，确认项目定位与核心流程。
2. 搜索一只股票，例如 `牧原股份` 或 `300308`。
3. 读取资料包，展示数据集和图表。
4. 展示多 Agent 历史报告或运行一次分析。
5. 用 `admin_view / admin_view` 进入后台，展示系统治理、股票数据、行情数据、新闻数据和访问与安全。
