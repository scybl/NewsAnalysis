PROJECT OVERVIEW A 股多源数据 · NewsCrawler · Multi-Agent Research Workspace

ValueScope

基于多 Agent 的 A 股金融投研分析平台。项目将股票行情、财务指标、新闻数据、本地资料库和分析审计链路整合为一个可复用的研究工作台。

Python LLM Application Multi-Agent MongoDB Docker Compose NewsCrawler AKShare
进入工作台 登录系统 新闻数据状态
01

主要目标

面向 A 股投研场景构建统一入口：支持股票检索、资料包生成、历史分析复用，并把行情、财务、公告和新闻数据沉淀为可重复读取的本地资产。

02

Agent 设计

根据不同分析任务动态编排市场、新闻、基本面、风险审计等角色，实现多轮分析、反方审计、结论修正与最终汇总。

03

工程链路

构建任务执行与观测链路，记录任务状态、调用历史、错误信息、分析结果和审计日志，支持后台追踪、问题定位与结果复用。

SYSTEM HIGHLIGHT

从数据源到投研结论的完整闭环

  • 整合股票行情、财务指标、分钟行情、公告、资金与新闻数据，统一存入本地资料包。
  • 拆分独立 NewsCrawler 服务，通过 MongoDB 与标准化 news.v1 文档契约解耦主系统。
  • 只读 Admin 视图可查看股票数据、行情数据、新闻数据和权限隔离，便于观察系统运行边界。
BOUNDARY

系统边界

采集层 多源行情、公告、新闻和资金数据适配，按统一字段沉淀到本地资料包。
分析层 多 Agent 根据任务类型拆分观点、审计风险并生成可追踪的分析结论。
运维层 后台查看任务、股票数据、行情数据、新闻数据和只读权限状态。
