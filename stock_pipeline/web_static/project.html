PROJECT OVERVIEW A 股多源数据 · NewsCrawler · Data Governance Console

ValueScope DataHub

面向 ValueScope 分析的数据采集、治理和展示平台。项目将股票行情、财务指标、新闻数据、本地资料库、冷备份和数据质量审计整合为一个可复用的数据工作台。

Python Data Platform Data Governance MongoDB Docker Compose NewsCrawler AKShare
进入工作台 登录系统 新闻数据状态
01

主要目标

面向 A 股数据资产构建统一入口：支持股票检索、资料包生成、历史数据读取，并把行情、财务、公告和新闻数据沉淀为可重复读取、可检查、可供分析消费的本地资产。

02

数据供给

通过统一资料包、新闻库、日 K、分时索引和冷备份状态，为下游 ValueScope 分析提供稳定、可追溯的数据输入。

03

工程链路

构建任务执行与观测链路，记录任务状态、调用历史、错误信息、分析结果和审计日志，支持后台追踪、问题定位与结果复用。

SYSTEM HIGHLIGHT

从数据源到可用数据资产的完整链路

  • 整合股票行情、财务指标、分钟行情、公告、资金与新闻数据，统一存入本地资料包和 MongoDB 热数据。
  • 拆分独立 NewsCrawler 服务，通过 MongoDB 与标准化 news.v1 文档契约解耦主系统。
  • 后台视图可查看股票数据、行情数据、新闻数据、冷备份和权限隔离，便于确认数据是否可供 ValueScope 分析使用。
BOUNDARY

系统边界

采集层 多源行情、公告、新闻和资金数据适配，按统一字段沉淀到本地资料包。
供给层 资料包、新闻证据、日 K 和分时索引按统一契约供下游 ValueScope 分析读取。
运维层 后台查看任务、股票数据、行情数据、新闻数据和只读权限状态。
