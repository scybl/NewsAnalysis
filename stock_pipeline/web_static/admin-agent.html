Agent API

/api/agent/v1
GET /health公开健康检查
GET /whoami验证 token 和 scope
GET /stocks/search?q=000001股票检索
GET /stocks/{code}/data读取本地资料包
POST /analysis-jobs提交异步多 Agent 任务
GET /jobs列出当前 token 的任务
GET /jobs/{job_id}轮询任务结果
GET /jobs/{job_id}/streamSSE 实时进度
GET /openapi.json机器可读接口合约

调用示例

curl / MCP 包装入口 
curl -H "Authorization: Bearer na_agent_xxx" \
  http://127.0.0.1:8765/api/agent/v1/whoami

curl -X POST http://127.0.0.1:8765/api/agent/v1/analysis-jobs \
  -H "Authorization: Bearer na_agent_xxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 000001-value-001" \
  -d '{"ts_code":"000001.SZ","analysis_type":"value_speculation"}'
